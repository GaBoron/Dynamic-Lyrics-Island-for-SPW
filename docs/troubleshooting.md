# 故障排查

> [文档首页](README.md) · [安装与更新](installation.md) · [使用与设置](usage.md) · [兼容性与限制](compatibility.md) · [开发指南](development.md)

本文只处理“功能本来应该可用，但实际没有按预期工作”的情况。

如果你只是想确认某个平台是否支持某项功能，请先查看 [兼容性与限制](compatibility.md)。

## 先做这 5 件事

遇到问题时，建议先按顺序检查：

1. 确认安装的是当前平台对应的插件 ZIP，并且插件已在 SPW 中启用；
2. 切换一次歌曲，必要时重启 SPW 后重新测试；
3. 歌词相关问题先确认 SPW 自己已经成功加载歌词；
4. 找不到词岛时，先在 SPW 插件设置中点击“找回词岛”；
5. 如果问题只在特殊配置下出现，先恢复到 1× 播放速度，并暂时关闭实验性多行歌词。

> [!TIP]
> 很多问题可以先通过“换一首本地歌曲 + 1× 播放 + 默认设置”判断到底是歌曲数据、歌词源、平台环境还是词岛本身。

## 安装与显示

### 插件没有出现在 SPW 插件列表

优先检查：

- 下载的是当前平台对应的插件 ZIP，而不是 `-source` 源码包；
- ZIP 没有被再次解压后错误放置；
- 使用的是兼容 Workshop API 的 SPW 版本。

Windows 手动安装时，插件 ZIP 应放在：

```text
%APPDATA%\Salt Player for Windows\workshop\plugins\
```

放入前请完全退出 SPW，完成后重新启动。

安装步骤见 [安装与更新](installation.md)。

### 插件已经启用，但词岛完全不显示

依次检查：

- “显示词岛”是否开启；
- 当前歌曲是否已经被 SPW 正常识别；
- 是否开启了“暂停时隐藏”；
- Windows 下是否开启了“全屏时隐藏”；
- 词岛是否位于另一块显示器或当前不可见区域。

最直接的恢复方式是：

**SPW 插件设置 → 找回词岛**

该操作会重新显示词岛并移回主屏幕顶部；Windows 下同时解除鼠标穿透。

`Ctrl+Shift+D` 也可以显示／隐藏词岛，但当前只在 SPW 内生效，不是系统全局快捷键。

### 词岛突然消失

重点检查：

- “暂停时隐藏”；
- Windows 下的“全屏时隐藏”；
- Windows 下的“鼠标穿透”；
- Windows 下的“悬停自动隐藏”。

动态壁纸、桌面增强软件或某些覆盖整个屏幕的窗口可能被 Windows 判断为全屏。如果关闭“全屏时隐藏”后立即恢复，通常属于这一类情况。

多显示器连接状态变化后如果词岛位置异常，直接使用“找回词岛”。

### 开启鼠标穿透后无法操作词岛

这是正常行为：开启后鼠标事件会直接传给词岛下方窗口。

可以通过以下入口恢复：

- 系统托盘关闭鼠标穿透；
- SPW 插件设置 → “找回词岛”。

如果同时开启“悬停自动隐藏”，鼠标进入词岛区域时词岛还会主动缩小隐藏，移开后恢复。

## 歌词与时序

### 只有歌名，没有歌词

词岛可以在暂时没有歌词行时显示歌曲信息，因此“能看到歌名”不代表 SPW 已经把歌词传给插件。

先确认 SPW 自己能够显示当前歌曲歌词，然后：

1. 切换到另一首歌曲再切回来；
2. 如果使用其他歌词插件，确认它已经完成歌词加载；
3. 必要时重新播放或重新加载当前歌曲。

本插件不会主动联网搜索歌词。需要自动获取逐字歌词时，可以搭配 [SPW-Lyrics](https://github.com/GaBoron/SPW-Lyrics)。

如果问题只在多个歌词插件同时启用时出现，请反馈时注明插件组合。

### 歌名也不正确，或切歌后仍显示上一首

先切换一次歌曲。

如果仍然错误，请记录：

- 出问题的是本地歌曲还是网络歌曲；
- SPW 自己显示的曲目信息是否正确；
- 是否只在插件刚启用后的第一首歌出现；
- 再切一次歌曲后能否恢复。

这类信息比单独截图更有助于区分宿主回调和插件状态问题。

### 逐字高亮整体偏早或偏晚

在 SPW 插件设置中调整“逐字高亮偏移 ms”：

- 正值：高亮提前；
- 负值：高亮延后。

这个设置只修正整体时间偏差，不会改变歌词源自身的时间轴质量。

如果不同歌曲需要完全不同的 offset，更可能是歌词源本身的问题。

### 调整播放倍速后明显不同步

当前对非 1× 播放速度的适配仍不完整。

改变倍速后，逐字动画和歌词时间轴可能明显不同步。该问题已记录在 [Issue #15](https://github.com/GaBoron/Dynamic-Lyrics-Island-for-SPW/issues/15)。

请不要通过不断修改 offset 来补偿倍速问题。排查其他时序问题时，先恢复到 1×。

### 实验性多行歌词显示异常

如果出现：

- 同时显示不应该重叠的歌词；
- 间奏期间保留了错误上一行；
- 某些歌曲正常、某些歌曲明显异常；

请先关闭“实验性多行歌词”，确认默认单行模式是否正常。

只有实验模式异常时，提交 Issue 请尽量附上：

- 具体歌曲；
- 歌词来源；
- 能稳定复现问题的时间位置。

## 封面、进度与频谱

### 看不到专辑封面

插件只读取本地可访问的封面：

1. 音频文件内嵌封面；
2. 同目录 `cover.jpg`；
3. 同目录 `cover.png`；
4. 同目录 `folder.jpg`；
5. 同目录 `folder.png`。

网络歌曲、不可访问文件或没有封面的歌曲会显示占位图，这是正常行为。

如果本地歌曲明确带有封面但仍无法显示，请换另一首本地歌曲比较，并确认 SPW 当前播放路径确实指向该文件。

### 开启封面取色后颜色没有变化

封面取色依赖插件先成功读取本地封面。

如果当前显示的是占位图，歌词、背景和频谱会继续使用默认颜色。

另外，取色不是简单读取封面中心像素。插件会优先选择占比较高的彩色区域，并尽量避开近黑和近白，所以结果可能与肉眼第一眼认为的“主色”略有不同。

### 展开后进度条不可拖动，或总时长显示 `--:--`

可拖动进度条需要可靠的歌曲总时长。

以下情况可能无法提供完整进度控制：

- 网络歌曲；
- 本地文件暂时不可读取；
- 音频格式或标签无法提供可靠时长。

这时歌词、上一首、播放／暂停和下一首仍可正常使用。

如果只有某一种本地音频格式持续无法读取时长，请在 Issue 中注明具体格式。

### Windows 实时频谱不动

先确认：

- 当前两侧信息设置包含频谱；
- 歌曲正在播放；
- 没有开启低性能模式。

实时频谱需要：

- Windows build 20348 或更高；
- 可用的 .NET Framework 4.x；
- 共享模式音频输出。

独占模式、ASIO 或其他绕过系统共享音频链路的输出方式可能无法被捕获。请先切换到共享模式测试。

如果实时捕获启动失败，插件会回退到模拟频谱，并在当前插件生命周期内提示一次原因。歌词显示不会因此停止。

### 低性能模式下频谱不像真实音乐

这是设计行为。

低性能模式会主动停止实时音频捕获，改用根据播放时间生成的轻量模拟频谱。

### Linux 没有实时频谱

Linux 当前没有实现 SPW 进程实时音频频谱，因此不会出现对应设置。

这属于平台能力限制，不是故障。详见 [兼容性与限制](compatibility.md#功能对照)。

## 菜单、设置与字体

### 右键／托盘菜单里找不到某个设置

快捷菜单不是完整配置页，只保留高频操作。

以下设置应到 SPW 插件配置页调整：

- 最大宽度；
- 背景不透明度；
- 圆角大小；
- 歌词字体与字重；
- 封面取色；
- 背景播放进度样式；
- 其他低频设置。

菜单里没有出现某项设置，不代表功能被删除。

### 字体显示异常、缺字或自定义字体效果不对

默认歌词使用插件内置 Noto Sans SC，不要求另外安装字体。

“歌词字体（可选）”留空时直接使用内置字体。

指定系统字体后：

- 只影响歌词；
- 找不到该字体时会回退到内置字体；
- 自定义字体缺少某个字符时会用内置字体补字；
- 自定义字体不一定支持所有字重，因此不同字重效果由字体本身决定。

极少数字符如果连内置字体也没有收录，仍可能显示缺字框。

## 性能

### 词岛卡顿或动画不流畅

先开启“低性能模式”测试。

低性能模式会：

- 降低常规刷新率；
- 简化逐字高亮；
- 关闭复杂逐字位移、缩放和辉光；
- 关闭部分过渡；
- Windows 下停止实时音频捕获；
- 关闭可选宿主歌词探测；
- 降低部分窗口状态检查频率。

如果低性能模式下仍然明显卡顿，请反馈时说明：

- Windows 还是 Linux；
- 系统版本；
- SPW 版本；
- 插件版本；
- 是否开启实验性多行歌词；
- 是否只在展开、拖动、切歌或逐字歌词时卡顿。

“整个 SPW 都卡”和“只有词岛动画掉帧”属于不同问题，请尽量区分。

## Linux

Linux 当前属于实验性支持。完整平台差异见 [兼容性与限制](compatibility.md#linux-实验性支持)。

### 词岛上右键没有菜单

当前 Linux 快捷设置入口在系统托盘中，词岛区域右键暂不提供菜单。

请使用：

- Linux 系统托盘菜单；或
- SPW 原生插件配置页。

这不是右键事件失效。

### 看不到托盘图标

插件优先使用 AppIndicator / Ayatana AppIndicator，不可用时尝试 GTK StatusIcon。

部分桌面环境默认没有可见托盘区域，或者需要额外启用 AppIndicator 支持。这种情况下即使词岛本身正常，也可能看不到托盘图标。

如果托盘不可用，仍可通过 SPW 原生插件配置页管理词岛。

### 拖动松手后短暂闪回原位置

这是当前 Linux 已知问题。

移动词岛后松开鼠标时，窗口可能短暂回到原位置，再回到新位置。最终位置保存正确时，一般不影响继续使用。

如果最终位置也保存错误，请另行提交 Issue。

### Windows 专属设置在 Linux 中消失

这是正常行为。

Linux 当前不会显示：

- 实时频谱；
- 频谱取色；
- 鼠标穿透；
- 悬停自动隐藏；
- 全屏时隐藏。

这些 Windows 配置值会保留，切回 Windows 包后仍可继续使用。

## 提交 Issue 前

如果以上步骤仍无法解决，请在 [Issues](https://github.com/GaBoron/Dynamic-Lyrics-Island-for-SPW/issues) 提交反馈。

建议至少提供：

| 信息 | 示例 |
| --- | --- |
| 平台 | Windows 11 / Linux |
| 系统版本 | Windows build、Linux 发行版 |
| SPW 版本 | 当前安装版本 |
| 插件版本 | Release 版本号 |
| 问题类型 | 歌词 / 封面 / 频谱 / 窗口 / 设置 / 性能 |
| 复现步骤 | 从启动 SPW 到问题出现的具体操作 |
| 是否稳定复现 | 每次 / 偶发 |
| 相关设置 | 多行歌词、低性能模式、穿透、全屏隐藏等 |
| 截图或录屏 | 尽量包含 SPW 与词岛状态 |

针对不同问题再补充：

- **歌词问题**：歌曲、歌词来源、出现异常的大致时间点；
- **频谱问题**：音频输出方式，是否使用 ASIO / 独占模式；
- **封面问题**：本地或网络歌曲、封面是内嵌还是同目录文件；
- **多显示器问题**：显示器数量、缩放比例、主屏；
- **Linux 问题**：桌面环境，以及 X11 / Wayland / XWayland 情况。

> [!NOTE]
> 请尽量描述“期望发生什么”和“实际发生什么”。单独写“不能用”通常很难判断问题发生在哪一层。
