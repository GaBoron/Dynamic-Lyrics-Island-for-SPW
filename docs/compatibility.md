# 兼容性与限制

## 平台支持

| 平台 | 适配情况 |
| --- | --- |
| Windows | 完整支持所有功能 |
| Linux | 在适配计划中 |
| macOS | 暂无计划 |
| Android / iOS / HarmonyOS | Salt Player 暂不支持插件功能 |

## 歌词与宿主限制

插件只接收 SPW 已加载的歌词，不搜索、不上传，也不修改歌曲或歌词文件。SPW 当前仅提供正在播放的歌词行，因此无法预告下一句或显示完整歌词列表。

歌词换行时机由 SPW 决定。若其他插件提前返回歌词，SPW 是否继续通知本插件取决于宿主调用顺序。

## 音频与封面限制

- 实时频谱依赖 Windows build 20348 或更高版本的进程回环能力。
- 独占／ASIO 输出可能无法被捕获，建议使用共享模式音频输出。
- 频谱只捕获 SPW 进程及其子进程，不读取系统混音或麦克风。
- 封面只从本地音频标签或同目录 `cover.jpg`、`cover.png`、`folder.jpg`、`folder.png` 读取；网络歌曲或不可读文件使用占位图。

## 界面限制

- `Ctrl+Shift+D` 只在 SPW 内生效，不是系统全局快捷键。
- 动态壁纸可能被识别为全屏窗口，导致开启“全屏时隐藏”后词岛消失。
- 字体回退不能修复字体未安装、字形覆盖不完整或字体自身渲染造成的问题。

更多实现边界和 API 依据见 [开发与构建](development.md)。
