## 推荐阅读顺序

第一次使用时，通常按下面的顺序即可：

1. [安装与更新](installation.md)：选择正确的平台包并完成安装；
2. [使用与设置](usage.md)：了解常用操作和主要设置；
3. [兼容性与限制](compatibility.md)：遇到平台差异或能力边界时查看；
4. [故障排查](troubleshooting.md)：只有实际遇到问题时再按症状查找。

开发者可以直接从 [开发指南](development.md) 开始，其中包含完整代码地图、主要数据流、构建方式和贡献约定。

## 文档分工

每篇文档只负责一种问题，尽量避免重复维护同一份说明：

- **安装与更新**：怎么装、下载哪个包、更新时怎么处理；
- **使用与设置**：功能怎么用、设置项有什么效果；
- **兼容性与限制**：什么能做、什么暂时不能做，以及不同平台的差异；
- **故障排查**：某个已经支持的功能没有按预期工作时怎么检查；
- **开发指南**：项目内部结构、代码职责、构建和贡献。

> [!TIP]
> 如果只是想快速解决一个现象，不需要从头阅读所有文档。直接打开 [故障排查](troubleshooting.md)，按症状定位即可。
