# 使用与设置

> [文档首页](README.md) · [安装与更新](installation.md) · [故障排查](troubleshooting.md) · [兼容性与限制](compatibility.md) · [开发指南](development.md)

本文介绍词岛怎么操作、主要设置分别做什么。平台是否支持某项能力，请查看 [兼容性与限制](compatibility.md)。

## 快速开始

安装并启用插件后，播放一首 SPW 已经成功加载歌词的歌曲即可看到词岛。

常用操作：

| 操作 | 效果 | 平台说明 |
| --- | --- | --- |
| 悬停词岛 | 展开歌曲信息、播放按钮和进度条 | Windows / Linux |
| 双击歌词区域 | 播放／暂停 | Windows / Linux |
| 点击或拖动进度条 | 跳转播放位置 | 需要可用的歌曲总时长 |
| 拖动词岛 | 调整位置并自动吸附 | Windows / Linux |
| 右击词岛 | 打开快捷设置菜单 | Windows；Linux 使用托盘菜单 |
| 托盘右键 | 打开常用快捷设置 | Windows / Linux |
| 在 SPW 内按 `Ctrl+Shift+D` | 显示／隐藏词岛 | 当前不是系统全局快捷键 |
| 插件设置 → “找回词岛” | 恢复显示并移回主屏幕 | Windows 下同时解除鼠标穿透 |

> [!TIP]
> 右键／托盘菜单只放高频操作。完整配置始终以 SPW 的插件设置页为准。

## 歌词显示

### 翻译

开启“显示翻译”后，如果当前歌词行带有翻译，会在主歌词下方显示第二行。

没有翻译的歌曲不会额外生成翻译内容。

### 逐字高亮与 AMLL 动效

带逐字时间信息的歌词可以使用：

- 平滑逐字高亮；
- 逐字抬升；
- 长音强调；
- 辉光；
- 歌词切换过渡。

普通逐行歌词仍以整行方式显示。歌词过长时会自动平移，避免无限拉宽词岛。

如果所有歌曲都存在固定的提前或延后，可以调整“逐字高亮偏移 ms”。具体排查见 [故障排查](troubleshooting.md#逐字高亮整体偏早或偏晚)。

### 实验性多行歌词

“实验性多行歌词”会尝试保留时间上仍未结束的已播歌词，并在重叠时同时显示多行。

该功能依赖比默认单行模式更多的宿主歌词信息，因此兼容性低于普通模式。出现异常时可直接关闭，不影响默认歌词显示。

## 外观

### 形状与圆角

“外观”可在以下形状间选择：

- 胶囊；
- 顶部刘海。

刘海会根据词岛位于屏幕顶部还是底部自动翻转；位于屏幕中部时使用胶囊轮廓。

“圆角大小 %”用于调节整体圆角程度。

### 字体

默认歌词使用插件内置 Noto Sans SC，并提供以下真实字重：

`100`、`300`、`350`、`400`、`500`、`700`、`900`

“歌词字体（可选）”留空时直接使用内置字体；填写已经安装的字体名称后，只替换歌词字体，缺失字形仍回退到内置字体。

自定义字体不一定真的包含所有字重，因此不同字重的实际效果由字体本身决定。

### 宽度与透明度

- “最大宽度”：限制词岛允许扩展到的最大宽度；
- “固定词岛宽度”：开启后不再随歌词长短收缩；
- “背景不透明度”：控制词岛背景透明程度。

## 封面、频谱与颜色

### 两侧信息

Windows 可以选择：

- 左侧封面 + 右侧频谱；
- 左侧实时频谱；
- 左侧专辑封面；
- 不显示两侧信息。

Linux 当前固定使用本地专辑封面，不提供实时进程频谱。平台差异见 [兼容性与限制](compatibility.md#功能对照)。

### 封面取色

插件可以从本地专辑封面提取代表色，并分别用于：

- 歌词高亮与辉光；
- 词岛背景；
- Windows 实时频谱。

取色会尽量避开近黑和近白区域，因此结果不一定等同于封面中心像素。

### 背景播放进度

可选择：

- 关闭；
- 背景注水；
- 顶部细线。

低性能模式下会关闭动态背景进度。

## 位置与展开方向

拖动词岛时，靠近当前显示器工作区的左／中／右和上／中／下区域会自动吸附，形成九宫格锚点。

锚点不只是保存位置，还决定缩放和展开方向：

- 顶部区域：内容向下展开；
- 底部区域：播放控件向上展开；
- 中部区域：使用居中的缩放行为。

多显示器连接状态变化后如果找不到词岛，可直接使用“找回词岛”。

## 播放控制

悬停词岛后可使用：

- 上一首；
- 播放／暂停；
- 下一首；
- 播放进度条。

进度条需要知道歌曲总时长。本地音频通常可以读取；网络歌曲或不可读文件可能无法提供可拖动进度条，此时其他播放控制仍可使用。

## 鼠标与自动隐藏

以下功能当前仅 Windows 提供：

### 鼠标穿透

开启后，鼠标事件会直接传递给词岛下方的窗口。

需要重新操作词岛时，可通过：

- 系统托盘；或
- SPW 插件设置中的“找回词岛”

解除穿透。

### 悬停自动隐藏

开启鼠标穿透后，可以再开启“鼠标经过时自动隐藏”。鼠标进入词岛区域后词岛会缩小隐藏，移开后恢复。

### 全屏时隐藏

前台窗口进入全屏时自动隐藏词岛。动态壁纸或覆盖整个屏幕的桌面软件有时也可能被判断为全屏窗口。

## 暂停时隐藏

“暂停时隐藏”在 Windows 和 Linux 都可用。开启后暂停播放时词岛隐藏，恢复播放后重新显示。

## 低性能模式

低性能模式用于降低持续运行成本，会主动简化或关闭部分高成本效果，包括：

- 降低常规刷新率；
- 简化逐字高亮；
- 关闭复杂逐字位移、缩放和辉光；
- 关闭部分过渡；
- Windows 下停止实时音频捕获，改用轻量模拟频谱；
- 关闭可选宿主歌词探测；
- 降低部分窗口状态检查频率。

> [!NOTE]
> 低性能模式不是“关闭所有动画”。它会保留必要的歌词时间推进和基本交互，只减少持续性高成本效果。

## 菜单与完整设置页

快捷菜单适合临时切换：

- 显示状态；
- 歌词显示；
- 性能模式；
- 外观与部分交互选项；
- 重置位置和恢复操作。

较低频的设置，例如最大宽度、透明度、圆角、字体、取色和背景进度样式，请在 SPW 的插件配置页调整。

Linux 的快捷设置入口位于系统托盘，词岛区域右键暂不提供菜单。
