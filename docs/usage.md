# 使用与设置

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 悬停词岛 | 展开歌曲信息、播放按钮和进度条 |
| 双击文字区域 | 播放／暂停 |
| 点击或拖动进度条 | 跳转播放位置 |
| 拖动词岛 | 调整并保存位置；靠近工作区边缘或中心线时自动吸附、居中，并选择九宫格缩放锚点 |
| 右击词岛 | 在一级分区菜单中调整常用与显示设置，或重置位置 |
| 在 SPW 内按 `Ctrl+Shift+D` | 显示／隐藏词岛；此快捷键不是全局快捷键 |
| 托盘右键 | 快速切换性能、外观、歌词与鼠标交互设置，或显示、解锁、重置位置 |
| 插件设置 → 找回词岛 | 恢复显示、关闭穿透并移回主屏幕顶部 |

> [!TIP]
> 开启鼠标穿透后，鼠标事件会传给下方窗口。需要调整词岛时，可从托盘菜单或 SPW 插件设置中解除穿透。

## 功能与设置

- 歌词动画：逐字歌词按 SPW 时间戳平滑高亮；普通逐行歌词保持整行显示，长歌词自动平移。
- AMLL 动效：支持逐字抬升、长音强调、辉光和弹性过渡。
- 翻译与字体：当前行有翻译时显示第二行；默认使用内置 Noto Sans CJK SC，也可只为歌词指定已安装字体，缺字时回退到内置字体。
- 频谱与封面：默认左侧显示本地音频封面、右侧显示 SPW 进程的四频段实时能量；也可沿用仅在左侧显示频谱或封面的模式，或隐藏两侧信息。大小跟随主歌词单行行高，边距和图文间距在普通／展开状态下同步调整。
- 封面取色：优先选择封面占比最大的彩色系并避开黑白，可分别应用到歌词高亮、背景和频谱。
- 桌面适配：支持九宫格缩放锚点、多屏找回、全屏隐藏和暂停隐藏。刘海在顶部／底部区域自动翻转，在中部区域恢复胶囊轮廓；底部区域的播放控件向上展开。

右键菜单只保留经常切换的项目。最大宽度、背景透明度、圆角、取色和可选歌词字体等完整设置请在 SPW 的插件配置页调整。

低性能模式约以 15 FPS 刷新，保留按歌词单元时间进行的简化高亮和轻量模拟频谱，同时关闭过渡、辉光、音频捕获和可选歌词探测，并降低窗口状态检查频率。

遇到显示或设置问题时，请查看 [常见问题](troubleshooting.md)；功能能力边界见 [兼容性与限制](compatibility.md)。
